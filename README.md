# Mad Lad Studios - Games for Kids

Welcome to **Mad Lad Studios**! This repository contains fun browser games for kids, made by a kid (and AI).

Jumping cars, collector crabs, fire trucks, and more!

## How to Play

1. Open any of the HTML files in your browser (e.g., `mad-car-game.html`) or visit [madladstudios.com](https://madladstudios.com/).
2. Follow the on-screen instructions for controls and gameplay.
3. Enjoy!

## Deployment

This site is deployed via GitHub Pages.
